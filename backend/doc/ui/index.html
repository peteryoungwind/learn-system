Structural Changes

相对上版的主要变化

PC 前端从一套页面，升级为两套独立系统

管理员端与用户端不再共用导航结构，避免管理操作干扰学习体验。

入口页承担系统分流与权限解释

管理员可进入两端，普通用户只进入用户端，并显式展示误入管理员端时的反馈。

管理员端单独加入系统切换语义

允许管理员从后台切回用户端视角，符合文档中的双端访问要求。

Open Assumptions

仍然保留的低风险假设

用户端与管理员端共用设计变量与基础组件

因此视觉保持同一品牌语言，但布局与任务密度已经分开。

登录页采用共用入口模式

如果后续你想拆成 `/admin/login` 与 `/login` 两套入口，也可以在这一版基础上再细化。

导入任务页聚焦任务视角

手工录入能力仍保留，但主页面更强调任务记录、结果与重试能力。

输出结构遵循 `index.html + styles.css + pages/*.html`。如果你认可这版双系统原型方向，下一步我可以继续做 handoff 或者直接转成 Vue 页面骨架。
